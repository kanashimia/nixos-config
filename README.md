# My nixos config.

It features:
- networkd and iwd for networking:
- systemd as a su and sudo replacement
- nftables instead of iptables as a firewall
- stalwart-mail as a mail server
- custom build of caddy as a web server 
- wireguard configured through networkd
- systemd in initrd
- zram as swap
- nix derivation diff upon rebuild
- chromium and steam xdg support
- realtime audio production config
- sway systemd integration
- sway tool for screenshoting in 8k
- custom perfectly engineered terraria module
- module for openobserve that is unused
- systemd credentials for secrets
